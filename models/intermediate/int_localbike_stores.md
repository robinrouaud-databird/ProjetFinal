{% docs int_localbike_stores %}

This model provides a summary of informations on stores

The main metric are :

    - nb_staff_by_store : total of employees by store
    - total_revenue_store : sum of order item amounts for orders completed by the store
    - volume_sales_by_store : sum of order item quantities for orders completed by the store
    - revenue_store_by_nb_staff : total revenue of store divided by number of employees

It provides a comprehensive view of each stock, allowing for easy analysis of order performance.
